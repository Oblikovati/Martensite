# Martensite 0.4.0

Surface measurements can select integration and face representation independently.
The owned result records the requested policy, face sources and estimate-or-unknown
evidence. Existing entry points retain their defaults and numerical behavior.
The CPU-limit fix restores exit code 2 with bounded diagnostic delivery on Unix,
including blocked output and retry after a transient setup failure.

Use the complete `martensite-0.4.0-source-workspace.tar.gz` SDK or the `v0.4.0`
Git tag for a coherent dependency graph. The source SDK includes locked Cargo
dependencies for offline production-library builds. Its users still provide an
installed toolchain and native platform libraries; dataset-backed tests require
separately provisioned original inputs. The package catalog reports individual
archive requirement compatibility. Published older `.crate` files retain their
original bytes and requirements.

Only packages whose source changed advance their versions:

| Package | Version |
| --- | --- |
| `martensite-tkernel` | 0.4.0 |
| `martensite-tktopalgo` | 0.4.0 |
| `martensite-process-policy` | 0.3.7 |
| `martensite-tkgeomalgo` | 0.3.7 |

The other seventeen packages retain their existing versions. Internal path
requirements select this SDK's foundation and topological packages at 0.4.0.
The coordinate-fitting fix shares one point snapshot for combined reads.

The publication plan creates thirteen source archives: the four changed packages
and nine unchanged versions with no archive in the verified publication history.
Eight existing archives are reused with their verified original bytes. The catalog
records their hashes and release origins.

The [bounded default-surface measurement](0.4.0-performance/README.md) records
unchanged outputs and observed process time and peak memory against v0.3.6.

The [local SDK acceptance record](0.4.0-sdk-acceptance/README.md) binds the successful
Linux packaging and consumer run to its exact producer revision. The supported
four-platform matrix on the final `main` revision remains pending before publication.
