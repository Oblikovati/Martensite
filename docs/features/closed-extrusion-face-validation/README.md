# Closed-extrusion face validation

This operation consumes an immutable coherent face input. It admits a full closed quadratic spline extrusion strip with line pcurves, matching cap spline bases and a genuine paired seam. Exact corner and located vertex incidences establish the rectangle quotient. The existing whole-support certificate proves injectivity on that quotient; exact metric decisions separately bind stored curves and endpoints to the support within their unchanged raw limits.

A coefficient upper bound can establish conformance of a full cap through the shared positive normalized basis. Failure of that sufficient bound leaves the check incomplete. An actual endpoint or stationary residual witness can establish a consistency violation. Unsupported representations, unresolved support separation, cancellation and exhausted work cannot publish a certificate.

Locations are replayed on owned datums with preserved aliases and powers. Every replay must agree bit-for-bit with its actual captured cache before it is used. Source coefficients are kept separate from scales and affine placements; no rounded transformed poles or sampled geometry are acceptance evidence.

The report owns its input, requested policy, ordered coverage, actual work, certified error uppers and read-only history. It describes the represented trimmed support and its declared consistency checks. Separation of tolerance-thickened surfaces, other faces, solids and complete modelling operations require their own coverage. A certificate never validates a later-mutated live entity.

Independent polynomial strips, topology and budget negatives, source isolation and process/thread comparisons exercise this Feature #213 operation. Validation results are recorded after the package and pull-request gates run.
