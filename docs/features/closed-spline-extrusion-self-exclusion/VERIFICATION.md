# Verification plan

Each claim has one minimum evidence path. Existing canonical checks remain mandatory before push.

| Claim | Owner and evidence |
| --- | --- |
| Exact represented spline pieces | TKMath unit controls compare Cox–de Boor coefficients with independent exact rational formulas for nonuniform quadratic spans and repeated knots. No sampled acceptance. |
| Sufficient extrusion theorem | Independent algebraic proof of the quotient kernel and equality implication; test axis-aligned and oblique nonzero directions. |
| Closed-curve acceptance | A four-quadratic rounded-diamond loop with independently disjoint quadrant interiors and exact shared endpoints, both windings and translated/scaled versions. |
| Additional contacts refuse | Independent bow-tie crossing, nonadjacent seam revisit, reversed/repeated span, line backtracking, constant span and tangent-contact fixtures. |
| Seam exclusions are exact | Distinguish exact closing endpoints from a one-bit-open endpoint; endpoint-to-interior contacts stay present. No parameter-box or coordinate-distance shortcut. |
| Source binding survives mutation | Mutate poles, weights, knots, direction and evaluation override after capture; old report remains identical, new capture differs or refuses. |
| No projected-map substitution | Nonuniform binary64 knots produce non-binary64 rational span coefficients; compare retained exact coefficients and reject a rounded-pole counterfeit. |
| Limits mean limits | Global split allowance consumed across at least two obligations; cancellation before/during extraction and numerical work; failed and unstarted work remain visible. |
| Predicate scope is honest | Nonconstant weights, unsupported degree/periodicity/trimmed intervals and overrides yield explicit incomplete results; invalid/nonfinite inputs yield typed errors. |
| Deterministic publication | Compare owned reports byte for byte across two processes and repeated invocations; use a total span/obligation order. Compile-time Send/Sync assertions. |
| Existing behavior is preserved | Before any shared-solver extraction, run its owned Bézier and sketch-incidence fixtures, then run them unchanged after the structural commit. |
| Required integration | Canonical TKMath/TKG3d affected package gates, then `cargo xtask pr --base release/0.7`; hosted checks including TSan/Sonar before merge. |

The observed application inputs will be stored as neutral owned numeric regression fixtures without external file paths or project provenance. They test the actual admitted representation and coverage. Their expected absence result must come from the completed exact predicate; their original application label is not an independent oracle.

A passing kernel certificate does not finish face trim/seam binding or application acceptance. Those remain separate gates. No new release, version, tag or dependency override is part of this work.
